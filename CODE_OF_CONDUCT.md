# Code de conduite

## Notre engagement

Nous nous engageons à faire de ce projet un espace accueillant, respectueux et
exempt de harcèlement pour toutes et tous, quel que soit l'âge, le handicap,
l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la
nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Comportements attendus

- Faire preuve d'empathie et de respect.
- Accepter les critiques constructives.
- Se concentrer sur ce qui est le mieux pour le projet et ses utilisateurs.
- Signaler les erreurs de bonne foi et proposer des solutions.

## Comportements inacceptables

- Harcèlement, insultes, menaces ou attaques personnelles.
- Discours discriminatoire ou haineux.
- Publication d'informations privées sans consentement.
- Perturbation délibérée des discussions ou des contributions.
- Contenu sexuel non sollicité.

## Application

Les mainteneurs peuvent supprimer, modifier ou refuser tout contenu contraire à
ce code, et prendre les mesures appropriées (avertissement, blocage, exclusion).

Pour signaler un comportement problématique, contactez le mainteneur via GitHub
ou utilisez le canal privé de sécurité :
<https://github.com/ZAGHTN/ZTVDPro/security/advisories/new>.

Les signalements seront examinés avec discrétion et de bonne foi.
